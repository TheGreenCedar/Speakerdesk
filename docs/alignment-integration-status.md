# Current alignment integration and limits

Transcript timing is required in the single transcription pipeline. Standard setup downloads the pinned source artifacts and deterministically prepares the MLX weights, verifies their hashes and runtime, and performs a GPU check before readiness. Existing installations reuse authenticated weights. Historical disabled preferences do not select a degraded transcription path. Missing or corrupt data blocks admission with a setup or retry action; runtime timing failures stop the accuracy pass while retaining existing canonical text and human edits. No implicit provider download occurs during inference.

The provider functionally supports all fourteen configured languages. Supplied Cohere text and raw/codepoint/UTF16 offsets remain unchanged. Arabic attached marks retain null independent mark times, and unspaced CJK uses explicit character/display units. Unsupported or uncertain units remain unresolved. Functional coverage is separate from accuracy calibration: independent coarse timing accuracy is calibrated only in English.

The accepted English calibration is `ami-english-coarse-v1-5ab4e661e62f`, exact model digest/hop320/origin0/score−20. Four held-out AMI clips (19.77 seconds), 42 uniquely associated words, passed frozen coarse highlighting/seek criteria. Combined endpoint median 30 ms/p95 188.5 ms; end-only p95 397.5 ms and four early offsets 350–490 ms remain disclosed. CTC emission envelopes are not phonetic edges. Neither this English subset nor shared vocabulary proves universal meeting or non-English timing accuracy. Conservative unknown boundary guards remain unchanged.

Provider readiness receipts bind the exact behavior source identity. This required-pipeline source change invalidates the previous receipt; a fresh check of the accepted source is required before activation. Cached weight identities and the English calibration remain unchanged. No new execution qualification is claimed by source rebinding.

Historical `alignment-*-proposal.json` and `alignment-source-handoff.md` retain earlier source-only proposals. Current source/runtime locks supersede optional-provider descriptions there. Exact frozen loader, signed native-library loading, aggregate resource and native acoustic acceptance remain separate release gates.
