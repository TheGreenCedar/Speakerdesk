# Portable selected-live ASR reuse

`Models` enables final decoder-result reuse by default only after the committed profile matches the configured `cohere_path`, all ten checkpoint/tokenizer files, installed MLX/MLX Speech/NumPy versions, eight distribution-relative decoder source files, six current routing/authority policy files, and the loaded provider's complete configuration, feature settings, training state and quantized projection dtype. Metal and the GPU default device/stream must match. Missing or changed data disables this optional cache and leaves fresh decoding available. The existing GPU guards also reject changing an enabled worker to a CPU device or stream.

The profile contains no machine paths, transcripts, authority snapshots or process-local identities. Every worker starts with an empty cache. The unchanged final-ASR algorithm creates fresh provider/tokenizer instance signatures, admits only selected complete immutable live results, and requires current revision/CAS/epoch/purpose eligibility for automatic final reuse. Current VAD, language routing, timing, ownership and assembly still run. Explicit retry remains fresh; human edits and cancellation keep their existing guards. Configuration-supplied experimental identity or qualification tokens cannot override the production profile.

Set `asr_final_reuse_mode` to `observe` for a real current-decode comparison, or `off`/null to disable the cache. Both observe and reuse require the verified profile. `Models.asr_reuse_profile` exposes activation status and namespace identity for qualification diagnostics. A matching source profile is not a claim that the final candidate or its frozen package has been executed.

The inherited qualification is the real three-process GPU Engine comparison on source `3a08593e391d527bc15b6f03064aaafcc04f13cb`: 15 versus 12 decoder calls, unchanged 33 worker publications, 34 host documents and all four exports, with cancellation, human edits, stale revisions and explicit-resume controls. Its immutable outcome SHA is `8c3b34eda40d096b944a4f206316f8d590698eb209235ce1bfe0906c5c0febed`. The portable namespace changes initialization and requires fresh actual controls and the retained full interview before release; those checks are pending when this patch is prepared.

The profile is SHA-pinned by its trusted loader. Policy hashes include the final `live_refinement.py` integration and exclude the profile and its loader to avoid recursive hash dependencies. Frozen packaging includes the profile, exact raw policy files and MLX Speech `pyz+py` sources, so installed distribution-relative checks remain meaningful. Build/source changes that alter a pinned policy disable optimization until the profile is deliberately updated and qualified. Source tests verify relocated/frozen-style paths; actual frozen runtime checks remain separate.
