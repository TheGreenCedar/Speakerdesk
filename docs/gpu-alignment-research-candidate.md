# Bounded GPU alignment research candidate

The isolated provider uses the existing Apache-2.0 cached CTC weights converted
from ONNX to MLX float32. Activation quantization is removed; this is not the
original FP32 model and does not claim CPU output equality. The fixed English
AMI coarse timing criteria pass under the distinct model digest and calibration
identity. Coarse emission envelopes are not phonetic trimming boundaries.

The original CPU model/calibration remains accepted for retained historical
reading evidence. New provider output retains its GPU identity; evidence is
never relabeled as another model. Raw Cohere text remains authoritative.

The import producer passes the exact decoded English physical PCM, absolute
sample anchor and text to optional alignment. The existing temporal activity
ledger supplies ownership, not the chunk's union of speaker IDs. Failed or
unavailable alignment retains words unassigned. Explicit resource violations
must also fail the qualification supervisor's final durable-marker check.

This is a research integration: coarse_alignment.py still binds qualified
research reports and cached artifacts under the task-9 workspace. Artifact
installation, dependency inventory, model licensing/provenance packaging and
portable runtime configuration remain required before product release. No
release/version bump, installed application, real meeting, native capture or
voice inference is modified. Strict GPU-only voice qualification remains a
separate unresolved application-wide requirement.
