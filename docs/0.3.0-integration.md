# 0.3.0 engineering integration

The isolated integration combines automatic local language routing and standard
B6 voice recognition. Settings defaults to Automatic language and recognition ON;
saved voices still require explicit enrollment consent and multiple clean clips.
A raw meeting track is checked once. Adding a name never enrolls a voice.

AUTO preserves blank review passages and language-decision metadata. Voice
eligibility follows finalized, single-speaker audio rather than ASR/language review
flags. Import and live split offsets reach the voice clip selectors; overlap
cannot supply enrollment or automatic matching clips. All original audio remains
available. Word timestamps and reliable overlapping-speech attribution are absent.

Packaging retains the pinned Whisper implementation and both conversion/upstream
notices, plus Core ML Tools 9.0, B6 artifact identity and frozen policy. Model
weights are downloaded separately. Version metadata is consistently 0.3.0; the
combined app requires Apple Silicon and macOS 15 or newer.

## Existing measured evidence

The B6 worker ran 72 predictions on 36 independent synthetic recordings,
including four known voices, two recurring unknown voices and two unseen held-out
voices. Frozen threshold 0.7264125328398843, margin 0.10003429964182987 and
minimum two clips passed 8 genuine/8 unknown held-out trials with zero observed
false accepts, false rejects or wrong identities. Report SHA-256:
`048c7163a8ad353b0a5aa2b79933deba603f4ecfdcd60dde09485f9b1937811c`.
Its shipped compact policy matches the report and independent fixture-manifest
hash. Wall time 12.237470 seconds; peak RSS 214,630,400 bytes.

The actual predictor selects `ct.ComputeUnit.ALL` through the compiled-model
constructor. Real predictions were completed; ALL permits CPU/GPU/Neural Engine
selection but does not prove which device ran each operation. No per-operation
GPU/Neural Engine placement evidence or converter/upstream parity exists. This
small synthetic pilot does not estimate recognition accuracy for real people,
rooms or microphones.

Earlier real NVIDIA/Cohere MLX streaming processed a 20.254-second two-voice
synthetic fixture in 23.624 seconds wall time, with peak MLX allocation
1,901,170,136 bytes and RSS 1,865,367,552 bytes. This predates AUTO/profile
integration. CPU suites substitute trained model outputs and cannot establish
GPU/Neural Engine execution or acoustic accuracy.
