# Interface captures

These images show the 0.7.1 editor in light and dark themes. They render the shipped HTML, CSS and JavaScript in installed Google Chrome with synthetic API responses, invented names and text, and silent audio. They do not demonstrate native capture, inference or voice enrollment.

The captured frontend at `3b9292af3e694bdfece8fff80c2cdc5eab057e81` is unchanged from release `5e3035de3e12609f75d5f75c39ee0e6db4285cb6`. Only the normal authentication template value was substituted. People and name-picker views were opened through their UI controls.

Meeting and People images are 2560 × 1800 pixels; name-picker images are 2560 × 2200. The browser used a 2× device scale and content-only bounds. Each image was inspected for clipping, errors and unrelated content. The website uses these same image bytes.
